# 2026-1-UDWJM-Terca-Noite-FAPA-05

Frontend Vue + Quasar com JSON Server

## Como rodar

API:

```bash
cd json-server
npm install
npm start
```

Frontend:

```bash
cd quasar-project
npm install
npx quasar dev
```

A API roda em `http://localhost:3000`. O frontend usa a variavel `VITE_API_URL` do arquivo `.env`.
